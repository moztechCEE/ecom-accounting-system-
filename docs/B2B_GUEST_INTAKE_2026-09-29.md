# B2B 免登入採購需求：本次實作範圍

狀態：2026-09-30 本地開發中，尚未套用資料庫遷移、啟用公開送單、寄送真實報價或在 DEV 驗收。此文件描述本分支待審程式，並非已上線功能。

## 顧客與業務流程

1. 顧客在獨立的免登入頁依人工維護的品牌、分類及關鍵字瀏覽已上架且明確同意匿名公開的商品。頁面與公開 API **只顯示建議售價**，小計僅供參考；不揭露常態價、活動價、團購主進貨價、客戶折數、成本或精確庫存。品牌須由業務確認後設定，不能僅憑 SKU 推斷。
2. 顧客填聯絡資料、公司、採購單號及品項數量後送出「採購需求」。後端重新檢查每個商品的公開資格並保存當時的建議售價快照，回傳可分享的公開採購單連結 `/b2b/order/{reference}`。連結只可查看品項、數量、牌價與受理狀態，不含聯絡資料、專屬價格或庫存；它不是正式報價或授權憑證。重送同一請求鍵不重建需求。送出時不建立 ERP 銷貨單、不預留或扣減庫存。
3. 授權業務在員工工作台查看待核實需求，人工核對聯絡資訊並配對既有客戶主檔；無效需求可留原因標記無效。業務選擇保留品項、調低需求數量並**逐項輸入未稅內部單價**，才將訪客需求轉為內部待核庫需求。牌價不會自動成為成交價；配對或轉單都不代表對方已同意報價，也不會建立銷單。
4. 人員檢視 ERP 庫存資料並逐項人工核庫，若缺貨可與客戶在 LINE 群組協調；系統不代發 LINE 訊息。核庫與後續修訂均保留稽核紀錄。全數核實後，業務確認當次數量、未稅單價及條件，產生不可改寫的正式報價版次。
5. 訪客需求的專屬報價須由業務核對收件人是否為目前啟用客戶主檔的 Email 或對帳 Email、記錄核實依據，再由系統寄送 24 小時內有效、只能查看該版的私密連結。LINE 僅提醒查收 Email，不能貼私密價格連結。客戶免登入檢視並明確按下接受；寄出、開啟連結都不是接受。改價或撤回會使舊版失效。
6. 客戶接受最新有效版後，仍須業務確認接單，系統才依接受版快照建立 ERP 銷售訂單與庫存預留，進入 WMS 交運；裝箱並非正式扣庫，後續仍依既有交運核銷流程過帳。

## 啟用與驗收邊界

- 匿名目錄、匿名送單與私人報價 Email 使用獨立功能開關，預設關閉。匿名送單還需專用限流密鑰與可信的代理來源設定；目前尚未在 Cloud Run 證實 `req.ip` 是可用的真實客戶 IP，公開 POST 不得啟用。私人報價須完成 SMTP、HTTPS 網址、客戶信箱核實及真實郵件驗收後才能啟用。
- 本次需以合成顧客與商品測試：未公開／停用商品拒收、只有 MSRP 可見、公司隔離、重送不重建、限流、未知欄位拒收、員工配對與轉單權限、版本撤銷、Email 憑證與明確接受、訂單快照及審計。其後才做 DEV 具名顧客、公開網頁、人工核庫、真實郵件和 WMS 交運的操作驗收。
- 本地程式與測試通過不等於 DEV 已佈署或真實顧客已可下單。上線前須把目前較新的 DEV 權限、產品成本遮蔽等變更合入隔離候選版，且只在 DEV 驗收；正式環境仍待使用者確認。
