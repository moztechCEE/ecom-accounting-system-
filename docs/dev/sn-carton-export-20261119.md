# 箱號倉儲明細整批 XLSX 匯出

開啟 SN 或無 SN 已啟用批次時，「箱號倉儲明細 XLSX」預設涵蓋全部箱號。可指定箱序，也可用「選取全部箱號」恢復整批範圍。移除前後端的 100 箱限制，以該批次實際箱數檢查範圍。

保留兩張工作表的既有欄位及完整箱內 SN。單件 SN／PDF 的原有限制、輸出權限、批次退回與入庫標記不變。匯出不扣庫存，不做 ECOUNT 過帳，不執行資料遷移。

WMS 箱號匯入仍為每個檔案最多 100 箱／10,000 SN；大型批次如需匯入，請按箱序分段下載。中英文頁面指南已區分匯出與匯入規則，並重新產生及驗證來源 hash。

驗證：實際 SQL 與 XLSX 讀回通過有 SN 102 箱／10,101 SN、無 SN 10,001 箱，逐筆核對箱號、數量、SN、品號、條碼、來源批次及末段範圍。原退回流程與新增匯出整合共 13 項通過。相關後端與指南 67 項、前端 SN 9 項、指南生成器 17 項通過；前後端 build 通過。瀏覽器使用合成資料驗證有 SN／無 SN 各 102 箱的預設全選、重新全選及真實 XLSX 下載。

基礎版本：`aea3e0cfedf64973efa5b2b1a0d0aea0e892f6bd`。僅更新 ERP DEV；正式 ERP 不在本次發布範圍。WMS 正式站以獨立來源 `a00d59f8ea90f743f1fdebb7eee3ceed51c82c99` 同步。實際發布結果以 Cloud Run readback 與工作區收據為準。
