- 發票／收款核對使用專用 read permission，不以 cases 權限代替。產品／匯入／操作紀錄不重放在首頁；額外授權者可切原營運管理頁。FAQ 不在新首頁／側欄；Source 既有 section 相容路由仍存在，不能稱後端與資料已刪除。
- 原 Source workbench `/dashboard` 仍能由「查看案件概況」開啟；首屏不自動載入它。第一次 overview 未開時不生成 iframe launch；其他 sections 繼續沿原 frame／ticket／ready guard。
- 收起已修改的 overview 有確認；打開／收起 overview 不應清 native 客服／收發草稿。兩個 forceRender 頁籤保留 native Queue 元件，Queue 卸載回報 false，parent 分別合併三份 dirty flags。路由離開與瀏覽器 Back 使用既有 blocker；原 unload guard 保留。
