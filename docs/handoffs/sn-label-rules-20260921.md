## 改了什麼

- 在既有「採購庫存 → SN 與標籤」草稿工作區更新年份算法，移除手動年份欄位，改由製造日期推導；日期缺漏或無效時不生成樣張 SN。
- 日期欄位改用既有 Ant Design DatePicker，避免內嵌瀏覽器原生日曆控制項異常。
- 增加分組鍵函式與分頁裝箱預覽：每箱顯示產品、實際數量、起訖 SN，並能展開逐號清單。只計算當前頁，避免一次建立數十萬筆 UI 資料。
- 草稿升為 v2；保留 v1 的舊手填年份供核對，但不再作為配碼來源。缺少製造日期時不推定日期；載入不會自動覆寫 localStorage，仍須按儲存。
- 介面分開顯示已確認規則與待確認事項；ERP SKU 與保固用國際條碼分開呈現。
- 既有 SVG 設計器沿用新樣張序號，仍保留 DRAFT 標示；本輪沒有改動 SVG 匯出流程。
